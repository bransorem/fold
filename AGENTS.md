# Project guide

## Stack and architecture

- This is a Bun workspace. The web app lives at the repository root and the API is the `server/` workspace (`@fold/api`).
- The web app uses TanStack Start and TanStack Router with React 19, TypeScript, Vite, and Tailwind CSS. Client routes and components are under `client/`; route files are in `client/routes/`.
- `client/routeTree.gen.ts` is generated by TanStack Router. Make route changes in `client/routes/`, then regenerate with `bun run generate-routes` rather than editing the generated tree by hand.
- The API is a Hono app deployed as a Cloudflare Worker. Its entry point is `server/src/index.ts`; app setup and routes are in `server/src/app.ts`.
- Better Auth is configured in `server/src/auth.ts`. The API uses Cloudflare D1 for auth data storage; schema migrations are in `server/migrations/`. Worker bindings and runtime settings are in `server/wrangler.jsonc`.
- The web app and API are deployed as separate Cloudflare Workers. The root `wrangler.jsonc` configures the web app; `server/wrangler.jsonc` configures the API.

## Development

- Install dependencies with `bun install`.
- Run the web app and API together with `bun run dev`. The individual commands are `bun run dev:web` and `bun run dev:server`.
- Apply local API database migrations with `cd server && bun run db:migrate:local`.
- Use `bun run lint` for Biome checks, `bun run type-check` for TypeScript checks, and `bun run build` to build both apps.
- Keep credentials and local overrides in environment files such as `server/.dev.vars`; do not commit secrets.

## Conventions

- TypeScript is strict. Keep shared browser-facing code in `client/` and Worker-specific API code in `server/`.
- Add API endpoints through the Hono app in `server/src/app.ts`; keep auth configuration in `server/src/auth.ts`. Use a unique file per API grouping (e.g. `/api/folded/*` in `server/src/folded/index.ts`)
- Update the D1 schema through a new migration rather than editing an already applied migration.
- Use Biome for formatting and linting (`bun run format` and `bun run lint`).
